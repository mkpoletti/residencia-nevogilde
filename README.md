# Residência Nevogilde

Site de apresentação de um T3 duplex com jardim em Nevogilde, Porto: hero com vídeo que avança com a rolagem, galeria, características, localização e pedido de visita.

Fotografias e planta: LUXIMOS Christie's International Real Estate, usadas com autorização. A imobiliária "Vale & Douro" e os contactos são fictícios.

Para ver localmente: `python -m http.server 4174` nesta pasta.
